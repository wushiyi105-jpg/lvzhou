# UI 说明：履舟

- **谁在什么时刻打开**：给正在投递某个岗位的人。
- **首屏任务句**：这个岗位，我的证据够吗。
- **主操作**：按「贴 JD 和简历 → 逐条对证据 → 导出岗位版」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：人事档案夹；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：人事档案夹。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给正在投递某个岗位的人：把 JD 要求逐条拉出来，和简历里的经历一一对上；缺证据就留待补，改写只来自已有事实。
